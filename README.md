# 课课通

> **个人课程与时间管理，让学习、工作与生活安排更加简单。**

课课通是一款面向个人用户的**课程时间管理与综合协同办公应用**，同时提供移动端和电脑端版本。

无论是在电脑前进行课程安排，还是使用手机随时查看课程和时间计划，都可以通过课课通方便地管理自己的课程、日程、事项和时间安排。

课课通适用于教师、学生、培训人员以及其他有课程和时间管理需求的个人用户。
